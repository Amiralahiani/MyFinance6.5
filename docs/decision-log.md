# Journal de decisions

## 2026-07-17 — Fondation du projet

- Nom du projet : `myfinance6.5`.
- Domaine : analyse d'etats financiers bancaires sur une periode donnee.
- Les canaux actifs sont l’API et l’interface web. La plateforme Testing les contrôle séparément ; aucun canal mobile n’est inclus dans ce dépôt.
- La fiabilite prime sur la fluidite : en cas d'ambiguite, le systeme clarifie ; en cas de manque de preuve, il ne conclut pas.
